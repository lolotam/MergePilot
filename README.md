# MergePilot

مراجعة Pull Requests بالذكاء الاصطناعي، **متعددة المزودين**: Claude وOpenAI وGemini بمفتاحك أنت.

- ملخص بالعربي.
- ملاحظات قليلة ومتحقَّق منها على السطور.
- بيفهم قواعد مشروعك (`CLAUDE.md` و`AGENTS.md`).
- بيقارن الكود بتوثيق نفس نسخ المكتبات اللي بتستخدمها.

> **الحالة:** تخطيط وتصميم. لسه مفيش كود قابل للتشغيل.

## المبادئ

1. **مفاتيح API يملكها العميل.** مفيش تسجيل دخول باشتراكات المستهلكين، ولا انتحال لأدوات تانية.
2. **مفيش تنفيذ لكود الـ PR** أثناء المراجعة.
3. **محرك واحد، وكذا غلاف:** GitHub Action الأول، وGitHub App بعدين.
