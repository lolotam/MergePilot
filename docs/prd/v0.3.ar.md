# MergePilot — الحالة الحالية والمتطلبات v0.3

**التاريخ:** 13 أكتوبر 2026. الوثيقة دي بتحدّث تخطيط v0.1 وv0.2 بالحالة المنفّذة، ومعاها قرار الاشتراكات [ADR-0019](../adr/0019-dashboard-subscription-auth.md).

## شكل المنتج

- `packages/engine`: محرك المراجعة، اختيار النماذج، تقسيم الـ PR الكبير، التحقق، الحَكَم، كشف الأسرار والتكلفة.
- `packages/github`: قراءة GitHub ونشر المراجعات وتنسيقها، مع منع التكرار والمراجعة التزايدية.
- `apps/action`: GitHub Action، بمفاتيح API أو Claude Code الرسمي.
- `apps/app`: Fastify API، Better Auth، مساحات العمل، خزنة المفاتيح، Postgres/Drizzle، BullMQ/Redis والـ workers.
- `apps/web`: لوحة React لإدارة الإعدادات، البوتات، المراجعات، الأسعار، المفاتيح والاشتراكات.

## بيانات الدخول للمزوّدين

| المزوّد | API key | اشتراك من لوحة التحكم |
|---|---|---|
| OpenAI | نعم | ChatGPT عن طريق بروتوكول Codex |
| Anthropic | نعم | Claude Pro / Max |
| xAI | نعم | SuperGrok / X Premium |
| Gemini وباقي مزوّدي الـ API | نعم | مش مضاف |

كل مساحة عمل ليها طريقة دخول نشطة واحدة لكل مزوّد. تغيير الطريقة بيستبدل بيانات الدخول، وقايمة النماذج بتتحدّث حسب الطريقة. تسجيل الاشتراك بيستخدم pi-ai، بنفس تكامل المشروع المرجعي DeepSeek Harness، وبيحفظ التوكنات في الخزنة المشفّرة.

الأدمن والمالك يقدروا يربطوا الاشتراك أو يفصلوه. المحاولات بتتربط بالمستخدم ومساحة العمل، مدتها 15 دقيقة، وبتتلغي لما يقفل نافذة الدخول. تجديد التوكن متزامن بين الـ web والـ workers، والفشل بيطلب تسجيل الدخول من جديد.

## الوظائف الموجودة

مراجعة PR مع سياق القواعد والمكتبات، تحقق من الملاحظات، بدائل صريحة ومعلنة، نموذج أقوى للتغييرات الكبيرة، تقسيم المراجعة على دفعات، حَكَم Jev، لوحة بوتات مراجعة متعددة، سجل تشغيل وتكلفة، أسعار تلقائية وتعديلات يدوية، تنظيف السجلات، ونسخة إعدادات احتياطية مشفّرة بكلمة مرور.

## التكلفة والأمان

- نداء الاشتراك بيحسب التوكنات لكن التكلفة الإضافية للـ API بتبقى صفر؛ ثمن الاشتراك عند المزوّد منفصل.
- نداءات الحَكَم والـ API المدفوع ليها أسعارها. بعد استخدام بديل مدفوع، تكلفة المراجعة بتفضل غير معروفة حسب ADR-0008.
- مفيش تشغيل لكود الـ PR ولا تثبيت لاعتمادياته. بيانات الدخول ما بتظهرش في الواجهة أو السجلات أو الـ prompts.
- الـ SaaS بيخزّن بيانات التشغيل والإعدادات وبيانات الدخول المشفّرة؛ الـ Action بيشتغل داخل GitHub Runner.
