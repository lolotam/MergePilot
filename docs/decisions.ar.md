## الدفعة 6 — 2026-10-12

### س18: تسجيل الطلبات وسجلات النظام المهيكلة (Structured Logging)

**طلب صاحب المشروع (بنصّه):**
«i want the server to log these requests and any reequests so in the future any issue will appear in the log»

**القرار والنتيجة:**
- بناء نظام تسجيل موحد (`core/logger.ts`) باستخدام Pino يخرج JSON Lines مع طوابع زمنية ISO وتحديد الخدمة (`service: 'web' | 'worker'`).
- تفعيل التسجيل في بيئة الإنتاج لخادم الويب (`web`) ومعالج المهام (`worker`) مع مستوى تسجيل افتراضي `info` قابل للتغيير عبر `LOG_LEVEL`.
- تسجيل كل طلب HTTP بسطر اكتمال مهيكل يتضمن `reqId`، المسار، كود الحالة، زمن التنفيذ، ومعرفات المستخدم ومساحة العمل وعنوان الـ IP، مع تعتيم كافة الأسرار والمفاتيح والهيدرز الحساسة.
- تسجيل أحداث النطاق (Domain Events) وأحداث معالجة المهام ومراجعة الـ PRs بالكامل.
- تدوير السجلات تلقائياً في Docker (`max-size: 10m, max-file: 5`).

## الدفعة 7 — 2026-10-12

### س19: إضافة مزودي Xiaomi MiMo واختبار الاتصال بنموذج مجاني أو محدد (Task X1)

**طلبات صاحب المشروع (بنصّها):**
- «i want to add xiomi provider with its models»
- «will these models will work ?» (عن إرجاع OpenRouter / OpenCode Zen أخطاء حصة رغم توفر نماذج مجانية عندهم)

**القرار والنتيجة:**
- إضافة مزودي Xiaomi MiMo المتوافقين مع OpenAI إلى سجل المزودين (`packages/engine/src/providers/`):
  1. `xiaomi` — بعنوان ثابت `https://api.xiaomimimo.com/v1` وبادئة مفتاح `sk-` ونموذج افتراضي `mimo-v2-flash` ومتغير بيئة `XIAOMI_API_KEY`.
  2. `xiaomi-token-plan` — بعنوان سنغافورة الافتراضي `https://token-plan-sgp.xiaomimimo.com/v1` وبادئة مفتاح `tp-` ونموذج افتراضي `mimo-v2-flash` ومتغير بيئة `XIAOMI_TOKEN_PLAN_API_KEY`، ومنطقة الصين كمزوّد ثابت منفصل `xiaomi-token-plan-cn`.
  3. مساحة التفكير: طرازا `mimo-v2-pro` و`mimo-v2-omni` يفكران افتراضيًا ويُحسب لهما الهامش الافتراضي لمخرجات التفكير (8192 توكن)؛ بينما `mimo-v2-flash` لا يفكر افتراضيًا. أسلوب التفكير للمزودين في السجل مضبوط على `none`.
- تحسين منطق اختبار الاتصال في السيرفر (`apps/app/src/api/provider-routes.ts`): عند عدم تحديد نموذج في الطلب وعدم وجود نموذج مسبق للمزود في مساحة العمل، يتم فحص قائمة النماذج (مخزنة مؤقتًا) وتفضيل نموذج مجاني (التي تنتهي بـ `:free` في OpenRouter، أو تحتوي على `free` في OpenCode Zen)، وإلا يُستخدم النموذج الافتراضي للمزود.
- واجهة الويب (`apps/web/src/settings/TestKeyButton.tsx`): إضافة قائمة اختيار منسدلة صغيرة للنموذج بجانب أيقونة الاختبار لكل مفتاح مملوءة من مسار النماذج وتضبط افتراضيًا على النموذج المختار من السيرفر، مع إظهار اسم النموذج المختبر في تلميح النتيجة.
