# ADR-0006: الاشتراكات عن طريق تشغيل أدوات المزودين الرسمية كما هي

> **تحديث 2026-10-13:** مسار Claude Code للـ Action مستمر. [ADR-0020](0020-dashboard-subscription-auth.md) بيستبدل قفل Codex ومنع تخزين اشتراكات الـ SaaS، وبيضيف دخول الاشتراكات في لوحة التحكم. القيود دي أدناه بتسجّل القرار السابق.

- **الحالة:** Accepted لمسار Claude Code (صاحب المشروع، 2026-10-11). مسار Codex لسه مقفول، وGemini مالوش وضع اشتراك
- **مرتبط بـ:** ADR-0002، ADR-0004، PRD v0.2 §5

## السياق

صاحب المشروع أكّد يوم 2026-10-11: «yes قصدك إن MergePilot يشتغل باشتراكات الناس».

الطريقة اللي في الإضافات المرجعية **ممنوعة**، وده لأنها:

- بتستخدم رقم تعريف (client ID) بتاع أداة تانية.
- بتنتحل شخصية Claude Code.
- بتجمع التوكنات وتجددها بنفسها.

بس المزودين نفسهم عاملين **طريق رسمي**. الكلام اللي تحت ده من صفحاتهم بتاريخ 2026-10-11.

**Anthropic** ([Legal and compliance](https://code.claude.com/docs/en/legal-and-compliance)):

- **ممنوع:**
  - إن مطوّر يعرض تسجيل دخول Claude.ai جوه تطبيقه.
  - إنه يمرّر طلبات بالنيابة عن المستخدمين على اشتراكات Free أو Pro أو Max.
  - إنه يجمع أو يخزّن أو يتوسّط في توكنات الجلسات.
- **مسموح:**
  - إن المنتج يشغّل **Claude Code الأصلي من غير تعديل**.
  - إن **كل مستخدم يسجّل دخوله باشتراكه هو** عن طريق Anthropic نفسها.
- **الشروط:**
  - الموافقة على Commercial Terms.
  - مفيش تعديل في الـ binary.
  - مفيش إلغاء لأي طريقة دخول جواه.
  - مفيش دفع أو إعادة بيع أو توسّط في الاستخدام.
  - مايتستخدمش اسم Claude Code في اسم المنتج.
- **ملاحظة مهمة:** حدود Pro وMax محسوبة على «استخدام فردي عادي».

**OpenAI** ([Codex auth](https://learn.chatgpt.com/docs/auth)):

- Codex بيدعم تسجيل الدخول بـ ChatGPT، وفيه device code للأجهزة اللي مالهاش شاشة.
- للـ CI والأتمتة: «API keys are still the recommended default for automation».
- فيه دليل متقدم لإدارة دخول ChatGPT في CI/CD.
- عندهم تحذير: «Don't expose Codex execution in untrusted or public environments».
- الصفحة مابتتكلمش عن المنتجات التالتة اللي بتستخدم دخول ChatGPT.

**Google:**

- ملقيناش طريقة دخول بحساب Google جوه CI لـ Gemini CLI.
- الطرق الموجودة: API key، أو Vertex عن طريق Workload Identity Federation.

## القرار

1. نضيف نوع تاني من المزودين اسمه **`AgentCliRunner`**، جنب مزودين الـ API (ADR-0003). النوع ده بيشغّل الأداة الرسمية **كما هي**، في وضع غير تفاعلي، وبيطلب منها ناتج JSON بالملاحظات:
   - `claude` (Claude Code)
   - `codex` (Codex CLI)
2. **المستخدم** بيسجّل دخوله بطريقة المزود الرسمية على جهازه هو. مثلًا مع Claude Code: `claude setup-token`. التوكن بيتحفظ في **GitHub Secrets بتاعة مستودعه هو**.
3. MergePilot **مابيقراش التوكن، ولا يخزنه، ولا يجدده، ولا يبعته لأي مكان**. دوره الوحيد إنه يمرّر متغير البيئة للأداة الرسمية وهو بيشغّلها. كل حاجة بعد كده (المراجعة، والتحقق، والنشر) هي نفس خط المراجعة.
4. **أمان التشغيل:** كود الـ PR مش موثوق، فالأداة بتشتغل **بصلاحيات قراءة بس**:
   - مع Claude Code: أدوات قراءة وبحث بس، من غير Bash ولا تعديل.
   - مع Codex: `--sandbox read-only`.
   - بالإضافة لـ: مفيش PRs جاية من forks، ومفيش مستودعات public في وضع الاشتراك.
5. **حدود الوضع ده:**
   - **الإصدار الأول (Action):** مسموح، لأن المستخدم بيشغّل الأداة الرسمية بحسابه على دقايقه.
   - **Claude:** ماشي حسب صفحة Anthropic، بشرط الموافقة على Commercial Terms، ونتأكد منها وقت التنفيذ.
   - **Codex:** **مقفول** لحد ما نلاقي نص رسمي بيسمح بيه في منتج طرف تالت، أو تأكيد مكتوب من OpenAI.
   - **Gemini:** مفيش وضع اشتراك. هيشتغل بـ API key أو Vertex بس.
   - **SaaS (لاحقًا):** ممنوع نخزّن توكنات اشتراكات العملاء على سيرفرنا. أي وضع اشتراك في SaaS محتاج تأكيد مكتوب من Anthropic Sales.
6. **ممنوع (من غير أي تغيير، ADR-0004):**
   - أرقام تعريف أو secrets مستلفة.
   - انتحال headers أو system prompts.
   - استدعاء API المزود مباشرة بتوكن الاشتراك.
   - تعديل الأداة الرسمية.
   - تجميع الحسابات.

## النتائج

**الإيجابي:**

- المستخدم يقدر يستخدم اشتراك Claude بتاعه، والطريقة اللي بنستخدمها المزود نفسه بيوصفها.
- MergePilot مش شايل أي توكن.

**السلبي:**

- الأداة الرسمية أبطأ وأتقل من استدعاء API مباشر.
- التحكم في شكل الناتج أقل.
- حساب التكلفة مش بالفلوس، بل باستهلاك الحصة.
- حدود الاشتراك ممكن تخلص بسرعة لو الفريق كبير.

**الالتزام:** الوضع ده بيعتمد على شروط ممكن تتغير، فلازم نراجع الصفحات الرسمية قبل كل إصدار.
