# ADR-0001: محرك مستقل + غلاف GitHub Action أولًا

- **الحالة:** Accepted (صاحب المشروع، 2026-10-11)
- **مرتبط بـ:** PRD v0.2 §4

## السياق

v0.1 كانت بتخطط لـ GitHub App من أول يوم. الـ App محتاج:

- سيرفر.
- استقبال webhooks موقّعة.
- طابور دائم.
- قاعدة بيانات.
- مفاتيح عملاء متشفرة.
- لوحة تحكم.
- عزل بين المؤسسات.

ده تقريبًا ٣–٤ أضعاف شغل المحرك نفسه.

المنتج هيتجرب **داخليًا الأول**، وهيتعمل كشغل خفيف جنب مشاريع تانية.

## القرار

1. منطق المراجعة كله هيبقى في `packages/engine`، والمحرك مابيعرفش هو شغال جوه إيه.
2. الإصدار الأول هيتسلّم كـ **GitHub Action** في `apps/action`، ومعاه أداة CLI محلية في `apps/cli` للتجربة.
3. الـ GitHub App هيبقى غلاف تاني في `apps/app` على نفس المحرك، في المرحلة التانية.

## النتائج

**الإيجابي:**

- مفيش سيرفر ولا قاعدة بيانات ولا أسرار عملاء عندنا في الإصدار الأول.
- جهاز GitHub المؤقت بيشتغل كصندوق معزول جاهز، والمستودع متنسخ عليه.

**السلبي:**

- كل مستودع لازم يضيف ملف workflow ومفتاح بنفسه.
- مفيش لوحة تحكم.
- الميزانية الشهرية صعبة من غير تخزين.
- PRs اللي جاية من fork مش بتوصلها الأسرار.

**الالتزام:** أي حاجة خاصة بالـ Action (زي `@actions/core` أو قراءة `GITHUB_EVENT_PATH`) ممنوع تدخل جوه `packages/engine`.
