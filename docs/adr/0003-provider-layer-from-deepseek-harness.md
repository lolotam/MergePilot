# ADR-0003: طبقة المزودين مبنية على تصميم DeepSeek Harness

- **الحالة:** Accepted (صاحب المشروع، 2026-10-11 — «نستخدم كود DeepSeek Harness ونبني Multi-Provider Engine خاص بينا»)
- **مرتبط بـ:** PRD v0.2 §3.2

**تحديث 2026-10-13:** [ADR-0019](0019-dashboard-subscription-auth.md) بيستبدل منع pi-ai ومسارات الاشتراك. الـ API adapters الحالية مستمرة، وpi-ai بيوفّر تسجيل الدخول وبروتوكولات الاشتراكات فقط. النص أدناه هو سياق القرار الأصلي.

## السياق

كان قدامنا ٣ اختيارات لطبقة المزودين:

1. Vercel AI SDK.
2. adapters نكتبها بنفسنا من الصفر.
3. طبقة DeepSeek Harness. ترخيصها MIT، © 2026 DeepSeek، ونسختها `0.2.1-alpha.2`.

صاحب المشروع اختار Harness أساس.

اللي في Harness ويستاهل ناخده:

- عقد `LlmAdapter` (`packages/llm/llm/src/index.ts`): فيه دالة إلزامية واحدة `stream()`، وهي بترجّع `StreamChunk` موحّد.
- شكل `types.ts`: الـ chunks، و`FinishReason`، و`TokenUsage`، ومعاه التخزين المؤقت للتوكنات منفصل.
- `adapter-failure.ts` و`error.ts`: أكواد أخطاء ثابتة.
- `retry-policy.ts`: سياسة إعادة محاولة لكل مزود.

المشاكل اللي فيه:

- لسه alpha.
- مربوط ببيئة تشغيل تقيلة (cordis، والجلسات، والـ replay).
- بيعتمد على `@earendil-works/pi-ai`، والمكتبة دي جواها مسارات OAuth بالاشتراكات وأرقام تعريف مستلفة.

## القرار

1. **مش هنعمل fork للـ Harness، ومش هنعتمد عليه كـ dependency.** هننسخ (vendor) ملفات العقد والأخطاء وإعادة المحاولة بس جوه `packages/engine/src/llm/`. كل ملف هيحتفظ بإشعار الحقوق الأصلي، وهيتسجل في `THIRD_PARTY_NOTICES.md`.
2. هنشيل أي ارتباط ببيئة التشغيل بتاعتهم: cordis وcontext وsession.
3. **مزودين MergePilot** هيبقوا adapters بنكتبها بنفسنا، وكل واحد بيطبّق `LlmAdapter`، وتحتها الـ SDKs الرسمية:
   - `@anthropic-ai/sdk`
   - `openai`
   - `@google/genai`
4. **ممنوع الاعتماد على `pi-ai`** أو على قايمة المزودين الجاهزة جواها.
5. هنضيف اللي ناقص Harness:
   - **جدول أسعار** وحساب التكلفة بالفلوس.
   - **ناتج منظّم للملاحظات** (structured output / tool call بـ schema).
6. هنثبّت نسخة المرجع اللي نسخنا منها (commit أو تاريخ التحميل) في `THIRD_PARTY_NOTICES.md` وقت النسخ.

## النتائج

**الإيجابي:**

- عقد مزود اتجرّب في مشروع كبير.
- أكواد أخطاء موحّدة من أول يوم.
- مفيش أي مسار اشتراكات داخل علينا.

**السلبي:**

- إحنا اللي هنصون الملفات المنسوخة.
- أي تحديث في Harness لازم نراجعه بإيدنا.
