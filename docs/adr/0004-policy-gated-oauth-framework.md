# ADR-0004: إطار OAuth مقفول بسياسة — بنتعلم من الإضافات من غير ما ننسخ مساراتها

> **Superseded للاشتراكات:** قرار [ADR-0020](0020-dashboard-subscription-auth.md) بيتيح دخول اشتراكات Codex وClaude وGrok من لوحة التحكم عن طريق pi-ai. القيود التاريخية أدناه مش سياسة التنفيذ الحالية.

- **الحالة:** Proposed، ومحتاج تأكيد صاحب المشروع على التفسير ده
- **مرتبط بـ:** PRD v0.2 §5، ADR-0002

## السياق

صاحب المشروع طلب: «نحلل طريقة الـ OAuth الموجودة في الـ Plugins ونبني Multi-Provider Engine خاص بينا».

التحليل وصل لحاجتين:

- **الهندسة نفسها كويسة:** في `dsh-plugin-subscriptions` فيه:
  - PKCE S256 مع `state`.
  - callback محلي على `127.0.0.1` و`::1`.
  - device flow.
  - `TokenManager` بيجدد التوكن مرة واحدة حتى لو جاله كذا طلب، وبيقرا المخزن تاني قبل التجديد، وبيفرّق بين الفشل الدائم والمؤقت.
- **الاستخدام اللي فيها ممنوع:** أرقام تعريف Claude Code وCodex وCopilot وAntigravity، وclient secret متسرّب، وانتحال headers وsystem prompts، وقراءة ملفات أدوات تانية، وتجميع الحسابات.

## القرار

1. نبني في `packages/engine/src/auth/` إطار OAuth عام:
   - `AuthMethod` (`pkce` / `device` / `oidc-federation`).
   - `TokenManager` بيجدد مرة واحدة، والقفل يقدر يشتغل على أكتر من سيرفر في الـ App.
   - إلغاء حقيقي عند المزود لما العميل يفصل حسابه.
2. **كل مسار OAuth مقفول افتراضيًا.** المسار مايتفتحش إلا لو سجلّه فيه:
   - `approval.docUrl`: مستند رسمي من المزود بيسمح لتطبيق طرف ثالث بالاستخدام ده.
   - `approval.clientIdOwner = "mergepilot"`: رقم تعريف مسجل باسمنا.
   - قرار مكتوب من صاحب المشروع.
3. **أمثلة بنتوقع إنها تتفتح بعدين (لسه هنتأكد منها):**
   - Google Cloud OAuth برقم تعريف بتاعنا، وVertex أو Bedrock عن طريق GitHub OIDC.
   - OpenRouter OAuth PKCE، اللي بيقول إنه مخصص لتطبيقات الطرف الثالث.
   - GitHub App user OAuth.
4. **ممنوع نهائيًا مهما كان الإعداد:**
   - OAuth بالاشتراكات الاستهلاكية (Claude.ai / ChatGPT / Gemini consumer).
   - أي client ID أو client secret مش بتاعنا.
   - انتحال هوية أداة تانية.
   - قراءة ملفات تسجيل أدوات تانية.
   - تجميع حسابات أو تدويرها.
5. **مفيش ولا سطر** من `dsh-claude-oauth` أو من مسارات الدخول في `dsh-plugin-subscriptions` بيدخل الكود. أفكار `TokenManager` وتصنيف أخطاء HTTP هتتكتب من الأول، أو تتنسخ مع إشعار MIT لو اتاخدت حرفيًا.

## النتائج

- الإطار هيبقى جاهز يوم ما مزود يعتمد مسار رسمي.
- المنتج مايعتمدش على ثغرة ممكن تتقفل في أي لحظة.

## تحديث 2026-10-11

صاحب المشروع أكّد إنه عايز MergePilot يشتغل باشتراكات الناس، وطلب نستخدم مسارات pi-ai للاشتراكات.

المسارات دي **مش هتتبني**. السبب إن صفحة Anthropic بتمنع بالنص كل حاجة منهم:

- تطبيق طرف تالت يعرض تسجيل دخول Claude.ai.
- تمرير طلبات على اشتراكات Free أو Pro أو Max بالنيابة عن المستخدمين.
- جمع أو تخزين أو توسّط في التوكنات.

المسارات دي كمان قايمة على أرقام تعريف بتاعة أدوات تانية، وعلى انتحال شخصيتها.

الطريق الرسمي للاشتراكات بقى قرار منفصل: [ADR-0006](0006-subscriptions-via-official-agent-clis.md).
