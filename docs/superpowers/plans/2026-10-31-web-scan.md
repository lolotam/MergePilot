# Website Security Scan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `subagent-driven-development` or `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. The owner's selected web-scan implementer is `opencode/glm-5.3-flash-free`; the controller reviews every diff and runs the project gates. Do not substitute another model without authorization.

**Goal:** Add the platform-admin-only website scanner specified in [ADR-0052](../../adr/0052-web-scan.md), with bounded requests, durable execution, coverage-aware findings, and private GitHub alerts.

**Architecture:** A new dependency-injected `packages/webscan` performs crawling, deterministic checks, comparison and report rendering without importing `apps/` or `packages/engine`. The app supplies SSRF-pinned transport, structural redaction, platform-global storage, queue orchestration and administrative authorization. Dashboard producers and consumers share schemas through `@mergepilot/app/contract`.

**Tech Stack:** TypeScript ESM, pnpm 12.11.2, Node >=22.19, Vitest, Fastify/Zod, PostgreSQL/Drizzle, BullMQ/Redis, React/React Query and the existing Arabic/English dictionaries.

## Proposed contracts

Create `packages/webscan/src/types.ts`. Names and units below are the contract shared by the package implementation tasks; API/store types may add ids and timestamps without putting database concerns into the package.

```ts
export type CheckId = 'headers' | 'cookies' | 'transport' | 'disclosure' | 'files' | 'active';
export type Validation = 'Confirmed' | 'Likely' | 'Indicator' | 'Informational';
export type Comparison = 'New' | 'Unchanged' | 'Fixed' | 'Not checked';
export type Severity = 'critical' | 'high' | 'medium' | 'low' | 'info';
export type CheckSwitches = Record<CheckId, boolean>;

export interface ScanLimits {
  maxRequests: number;
  maxPages: number;
  maxActiveLinks: number;
  requestsPerSecond: number;
  requestTimeoutMs: number;
  maxResponseBytes: number;
  totalTimeoutMs: number;
}

export interface PathRule { path: string; kind: 'exact' | 'prefix' }
export interface ParameterRule { path: string; parameters: readonly string[] }
export interface ScanScope {
  hostname: string;
  baseUrl: string;
  crawlPaths: readonly PathRule[];
  blockedPaths: readonly PathRule[];
  parameterizedPaths: readonly ParameterRule[];
  activePaths: readonly ParameterRule[];
  extraFilePaths: readonly string[];
}

export interface ScanInput {
  scope: ScanScope;
  limits: ScanLimits;
  checks: CheckSwitches;
  contact: string;
}

export interface ScanProgress {
  requests: number;
  pages: number;
  elapsedMs: number;
  phase: 'crawl' | 'checks' | 'complete';
}

export interface ScanDependencies {
  // Requests contain transient raw URLs. Implementations must never log them.
  fetch: (url: string, init: { method: 'GET' | 'HEAD'; signal: AbortSignal }) => Promise<Response>;
  now: () => number;
  sleep: (milliseconds: number, signal: AbortSignal) => Promise<void>;
  signal: AbortSignal;
  onProgress: (progress: ScanProgress) => void;
}
```

The injected `fetch` must apply the site's validated hostname, pinned address, size/time caps and live worker authorization/lock checks. `runScan` independently enforces the same host/scheme/port and request-budget restrictions. Do not expose an option that bypasses public-address validation in production.

The package returns only safe catalogue findings, occurrence identities, normalized structural evidence and coverage. Raw `Response`/HTML/URLs with values never escape into the result. The app performs its additional engine redaction before persisting the result. Reports consume the stored safe result, not raw transport data.
